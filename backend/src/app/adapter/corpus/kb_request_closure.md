# How a request is closed

Closing a customer request is a high-risk write, so the agent proposes the status
change and a human approver confirms it before the request moves to resolved.
Before proposing a closure, verify the customer's identity and confirm the work
described on the request is finished. For duplicate requests, close the duplicate
only and keep the original request open. Enterprise-tier customers may ask for an
expedited closure, which is approved by a Tier-2 agent. Always record the closure
reason as a case note on the request so the timeline stays auditable.
