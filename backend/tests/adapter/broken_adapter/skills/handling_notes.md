# Skill: Recording what happened

Use when the outcome of a turn needs to be written down for whoever picks it up next.

- Write the note against the record it belongs to, not the conversation.
- One note, one fact: what changed, when, and on whose authority.
- Never restate the caller's words as a finding; separate what was reported from what was
  verified.
- If nothing changed, say so explicitly — an empty note is worse than none.
